# SwarmRank

A simple SwarmRank Engine for Auto Scaling.

SwarmRank is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple SwarmRank Engine for Auto Scaling

## Key Features

- A simple SwarmRank Engine for Auto Scaling

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/SwarmRank.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SwarmRank is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
